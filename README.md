## Программы

### Программа №1: Перегрузка оператора += для класса "Обыкновенная дробь"
- **Файл:** `program1.cpp` (исходный код из файла 7-2025.txt)
- **Описание:** Создание класса `numbers` для представления обыкновенных дробей. 
  Перегрузка оператора `+=` для сложения дробей по правилу: 
  a/b += c/d → (a·d + c·b)/(b·d). Демонстрация работы на трёх дробях.

### Программа №2: Пользовательский манипулятор вывода
- **Файл:** `program2.cpp` (исходный код из файла польз_манип.txt)
- **Описание:** Создание функции-манипулятора `doneline` для потока `ostream`, 
  выполняющей перевод строки. Демонстрация использования в цепочке вывода `cout`.
