НАЧАЛО
1. Подключить заголовочный файл <iostream>
2. Объявить использование пространства имён std
3. Определить функцию-манипулятор doneline(ostream& stream):
   3.1. Принять ссылку на ostream (параметр stream)
   3.2. Выполнить: stream << '\n'
   3.3. Вернуть ссылку на поток: return stream
4. Начало функции main():
   4.1. Установить локаль: setlocale(LC_ALL, "ru")
   4.2. Выполнить вывод: cout << "Первая строка" << doneline << "Вторая строка"
   4.3. return 0
5. КОНЕЦ
